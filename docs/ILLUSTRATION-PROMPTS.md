# Ludwig — illustration prompts

52 pictures: two for each of the 26 readings.

- **Concept** shows the idea itself.
- **Example** shows the everyday example from that reading.

Each reading already has a diagram in the app. These pictures go alongside it.

## How to make and send them

1. Paste each prompt into your image generator (Midjourney, DALL·E, Ideogram, Gemini, etc.).
2. Save each image with **exactly** the filename shown (for example `picture-concept.png`). PNG, JPG or WEBP are all fine.
3. Put all the images in one folder, zip it, and send the zip to Claude.
4. Claude places them in `assets/illustrations/`. The app shows each picture automatically next to its reading.

You don’t need all 52 at once. Any subset works, and missing pictures are simply skipped.

Tips: landscape 4:3, around 1600×1200. Ask for **no text in the image**, since generators often misspell words. Using the same style sentence every time keeps the set consistent with the app’s existing artwork.
